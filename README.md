# effecttrace.github.io

Source of the [EffectTrace](https://github.com/effecttrace/effecttrace) website, served by GitHub Pages at <https://effecttrace.github.io/>. It is a static site written in plain HTML, CSS and vanilla JavaScript with no build step, no external fonts, scripts or trackers, and a strict Content-Security-Policy; the results, experiments and replay pages render whatever is in `data/` at load time.

Preview locally:

```bash
python3 -m http.server 8000
# then open http://127.0.0.1:8000/
```

`data/` is generated by `make test-results` in the main repository and should not be edited by hand. Validate the site with `python3 scripts/site_check.py ../effecttrace.github.io` from the main repository.
